# Writing Style

## Tone

Default to polite Japanese (です・ます調).

Aim for:
- readable;
- direct;
- informed;
- calm;
- engaged without excessive hype.

## Paragraphs

Keep paragraphs relatively short.

Each paragraph should normally do one job:
- describe an event;
- explain a consequence;
- interpret a detail;
- transition to the next scene.

Avoid wall-of-text blocks.

## Headings

Prefer specific headings based on what actually happens.

Good:
- 「過去へ進む斬撃」
- 「巫女の神通力と救世権現の剣」
- 「封印解除後の最初の攻防」

Weak:
- 「衝撃の展開」
- 「驚きの真実」
- 「まさかの結末」

## Recap

Write the recap in chronological order unless another structure is clearly better.

Do not inflate minor beats into separate headings.

## Analysis

When moving from fact to interpretation, signal it clearly.

Useful phrasing:
- 「ここで気になるのは〜です」
- 「この描写から考えると〜」
- 「作中では断定されていませんが〜」
- 「個人的には〜と感じました」

## Avoid filler

Delete sentences that merely repeat the previous sentence.

Avoid generic filler such as:
- 「今後の展開から目が離せません」
- 「ますます面白くなってきました」
- 「非常に興味深いですね」

Use these only when followed by a specific reason.

## Spoilers

If the article is explicitly a spoiler article, do not repeatedly warn about spoilers inside every section.

A single clear spoiler notice is enough when needed.

## Character and terminology consistency

Preserve:
- official character names;
- technique names;
- chapter numbering;
- factions;
- locations;
- supernatural terminology.

If the user provides uncertain spelling, do not silently "correct" it unless verified.

## Site adaptability

If the user supplies site-specific rules, those override these defaults unless they conflict with factual integrity.
